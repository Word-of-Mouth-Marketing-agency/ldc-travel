# Official Documentation Checked

Context7 was requested by the project brief but is not available in this environment. The following current official documentation was checked as the fallback before selecting versions and integration patterns:

- Next.js `create-next-app` CLI and App Router: https://nextjs.org/docs/pages/api-reference/cli/create-next-app and https://nextjs.org/docs.
- Payload installation and supported software ranges: https://payloadcms.com/docs/getting-started/installation.
- Payload PostgreSQL adapter: https://payloadcms.com/docs/database/postgres.
- Payload official same-codebase route/layout examples: https://github.com/payloadcms/payload/tree/main/templates/with-postgres.
- Tailwind CSS with Next.js: https://tailwindcss.com/docs/installation/framework-guides/nextjs.

The verified constraints used here are Node.js 20.9+, Next.js 16.2.6+ compatibility for the installed Payload release, pnpm support/preference, `@payloadcms/db-postgres`, `withPayload`, Payload admin/API route wrappers, and Tailwind’s current PostCSS setup.
